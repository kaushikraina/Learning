# Learning 🚀

Full-Stack Web Development & Blockchain Learning Projects

This repository contains multiple projects built to explore modern web development, backend architecture, and blockchain integration using Ethereum.

---

## 📁 Projects Overview

### 1️⃣ SmartBrain (Frontend)
React-based face detection web application.

**Tech Stack**
- React.js
- CSS3
- JavaScript (ES6+)

**Features**
- Image upload
- AI face detection
- User authentication
- Responsive UI

---

### 2️⃣ SmartBrain API (Backend)
Express.js REST API powering the SmartBrain frontend.

**Tech Stack**
- Node.js
- Express.js
- JWT Authentication
- MongoDB / PostgreSQL

**Key Endpoints**
- `POST /signin`
- `POST /register`
- `POST /imageurl`
- `PUT /image`
- `GET /profile/:id`

---

### 3️⃣ Blockchain Backend
Web3 integration layer for Ethereum smart contracts.

**Tech Stack**
- Web3.js
- Solidity
- Ethereum

**Features**
- Smart contract interaction
- Transaction management
- Event listening

---

### 4️⃣ DrugTrace (Supply Chain DApp)
Blockchain-based drug supply chain tracking system.

**Features**
- Drug batch tracking
- QR code verification
- Immutable blockchain records
- Authenticity verification

---

## 🛠 Tech Stack Summary

- **Frontend:** React.js  
- **Backend:** Node.js + Express  
- **Database:** MongoDB / PostgreSQL  
- **Authentication:** JWT  
- **Blockchain:** Ethereum + Web3.js  

---

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/kaushikraina/Learning.git
````

Install dependencies inside each project folder:

```bash
npm install
```

Run the respective project:

```bash
npm start
```
